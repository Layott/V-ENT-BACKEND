## Traps met today

- A fresh worktree fails the commit hook until the backend `.env` is copied in and `pnpm install --frozen-lockfile
  --prefer-offline` has run in the frontend worktree.
- A new server code needs its `api.<CODE>` key in en, fr and pt in the frontend worktree of the same branch before
  the backend commit passes (check-server-codes reads the paired worktree).
- Inserting dictionary keys with a regex `.*` eats the `\r` of CRLF lines; git then treats dictionaries.js as binary
  and diffs all 34,000 lines. Anchor on `[^\r\n]*`.
- `tests_feeds` errors about one parallel run in four (user pk collision); fixed on BE #265 by C.
